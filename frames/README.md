## Import into Figma

1. Open your [Nothing AI OS Concept](https://www.figma.com/design/1Xh7OhSwUO6tJRskSraIKU/Nothing-AI-OS-Concept?node-id=2-3) file.
2. Drag each PNG onto the canvas, or use **Place image** (Ctrl/Cmd + Shift + K) and select these files.
3. Resize/crop to your frame size (e.g. 375×812 for phone) if needed.
4. Name frames to match the list above for consistency.

Each image includes the full presentation (title, phone frame, mode switcher) so you can crop to just the phone screen in Figma if you prefer.
